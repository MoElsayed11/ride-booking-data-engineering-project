# 🚀 Ride Booking Data Engineering Project

## 📌 Overview
Built an end-to-end data engineering pipeline using Databricks and PySpark to process ride booking data and generate business insights.

## 🏗 Architecture
- Bronze Layer: Raw data ingestion
- Silver Layer: Data cleaning and transformation
- Gold Layer: Business KPIs and analytics

## 🛠 Tech Stack
- Apache Spark (PySpark)
- Delta Lake
- Databricks

## 🔄 Pipeline Steps
1. Ingest raw CSV data into Bronze table
2. Clean and transform data in Silver layer
3. Generate KPIs and analytics in Gold layer

## 📊 Key Insights
- Revenue trends by vehicle type
- Peak booking hours
- Cancellation analysis
- Customer and driver behavior

## 💡 Key Features
- Handled real-world dirty data (nulls, corrupted timestamps)
- Implemented Medallion Architecture
- Built scalable and modular pipeline
